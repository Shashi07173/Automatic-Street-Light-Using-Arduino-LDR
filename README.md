# Automatic Street Light Using Arduino LDR

## Project Overview
This project is an Arduino-based automatic street light system that uses an LDR (Light Dependent Resistor) sensor to detect the surrounding light intensity and automatically control an LED.

## Components Used
- Arduino Uno
- LDR Sensor
- Resistor
- LED
- Breadboard
- Jumper Wires

## Technologies Used
- Arduino
- C/C++ (Arduino Programming)
- LDR Sensor

## Working
The LDR sensor measures the surrounding light intensity. When the environment becomes dark, the Arduino turns the LED ON automatically. When sufficient light is detected, the LED turns OFF.

## Features
- Automatic light control
- Light intensity detection using LDR
- Simple and low-cost circuit
- Energy-efficient operation
